## Известные расхождения и дефекты (найдено 2026-11-10)

1. **58 задач против 71.** Коммит `2dc6109` заявляет 71 задачу, в `plans/ai-agents-yg.json` их 58. Либо часть задач не попала в план, либо удалена из него после создания. Сверять по живой доске через API.
2. **Команды `/menu` в коде нет.** В `telegram-bot.js` слово `menu` не встречается ни разу; реализованные команды: `/start`, `/help`, `/who`, `/allow`, `/deny`, `/approve`, `/approvals`, `/drafts`, `/modx`, `/reset`, `/task`, `/status`. Меню, о котором шла речь, живёт в другом проекте или не запушено в этот репозиторий.
3. **Чек-листы, вероятно, не создаются.** `scripts/seed-board.js` отправляет `checkListItems` через `PUT /tasks/{id}` внутри `try/catch`, который только пишет предупреждение. Если API такой формат не принимает — чек-листы молча теряются. Проверять на живой доске.
4. **Метки не отправляются.** В плане у задач есть `labels` (`critical`, `stability`), но `createTask()` в `seed-board.js` их игнорирует.
5. **Дублирование HTTP-клиента.** `lib/yougile-client.js` умеет только задачи и колонки; `scripts/seed-board.js` содержит собственный клиент с ретраями и rate-limit. Нужен единый `lib/yougile-admin.js`.
