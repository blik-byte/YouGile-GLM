# steward.php — управление YouGile с обычного хостинга

Зачем: сервис на Render недоступен из вашей сети и с серверов агента, а агенту нужно уметь создавать проекты и менять задачи. Этот скрипт работает на вашем хостинге и обращается к `api.yougile.com` напрямую.

## Установка

1. Создать на хостинге папку с неочевидным именем, например `steward-7f3a`.
2. Загрузить туда два файла: `steward.php` и `config.php`.
3. `config.php` сделать из `config.example.php`: вписать свою строку доступа и ключ YouGile.
4. Рядом положить `.htaccess`, чтобы `config.php` не открывался из браузера:

```
<Files "config.php">
  Require all denied
</Files>
```

5. Проверить связь: открыть в браузере

```
https://ваш-домен/steward-7f3a/steward.php?ping=1&token=ВАША_СТРОКА
```

Должно вернуться `{"ok":true,"user":"AI Ассистент",...}`. Если вернулось `{"error":"Сеть: ..."}`, хостинг не может достучаться до YouGile — тогда напишите мне, разберёмся.

## Операции

Все запросы — GET, в каждом нужен параметр `token`.

### Создать проект с задачами

```
.../steward.php?token=…&project=Редизайн магазина&tasks=Семантика|Аудит|ТЗ на тексты
```

- `tasks` — через вертикальную черту;
- `columns` — свои колонки, тоже через черту (по умолчанию четыре стандартные);
- `dryRun=1` — только показать, ничего не создавать.

Ответ — JSON: сколько досок, колонок и задач создано, сколько уже было, какие ошибки. Повторный вызов не создаёт дублей.

### Статус задачи

```
.../steward.php?token=…&task=ИД_ЗАДАЧИ&completed=1
.../steward.php?token=…&task=ИД_ЗАДАЧИ&completed=0
.../steward.php?token=…&task=ИД_ЗАДАЧИ&column=В работе
```

### Правка

```
.../steward.php?token=…&kind=task&id=ИД&title=Новое название
.../steward.php?token=…&kind=task&id=ИД&description=Новый текст
.../steward.php?token=…&kind=project&id=ИД&title=Новое название проекта
.../steward.php?kind=board или kind=column — аналогично
```

### Чего нет

Удаления. Намеренно: GET-запросы попадают в историю и логи, а удаление необратимо.

## Безопасность

- Строка доступа (`token`) — длинная и случайная, не короче 32 символов.
- Ключ YouGile лежит в `config.php`, а не в самом скрипте: так его проще заменить, не переписывая логику.
- Если строка доступа утечёт, максимум, что можно сделать — создать проект или поменять статус задачи. Доступа к сервису на Render она не даёт.
- Менять строку доступа можно в любой момент: поправить `config.php` и обновить инструкцию агента.
